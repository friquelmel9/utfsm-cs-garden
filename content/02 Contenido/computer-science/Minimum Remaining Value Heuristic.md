# Minimum Remaining Value Heuristic

The Minimum Remaining Value [[Heuristic Techniques|Heuristic Technique]] chooses the next variable based on the size of the domain, prioritizing the one with less possible values.

> [!tip] 
> This one works well with [[Conflict Backward Jumping|CBJ]], finds the conflict earlier.
